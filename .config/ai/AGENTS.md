# Global Agent Instructions

- Never use em-dash (—), prefer normal dash (-)
- Never use eyebrow titles, kickers, or overlines in interfaces, designs, or
  documents: small labels above a main heading, often uppercase, letter-spaced,
  or monospace, such as "CHECKOUT PILOT" above "What ships next?". Start with the
  main heading and put necessary context in the heading or body text.
- For public comments, PR titles, descriptions, issues, etc always use the Humanizer skill to avoid bloated AI-style language
- Never author or co-author commits as your LLM - always use my git
